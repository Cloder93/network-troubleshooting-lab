# Windows Network Troubleshooting Lab

## Overview
Hands-on Windows network troubleshooting lab focused on diagnosing network configuration, connectivity, DNS resolution, DHCP, latency, and HTTPS connectivity.

## Environment
- Operating System: Windows 11
- Device: Acer Nitro 5 laptop
- Tools: Command Prompt, ipconfig, ping, tracert, nslookup, and curl

## Troubleshooting Exercises

### 1. IP Configuration
- Inspected network adapter configuration.
- Reviewed IP address, subnet mask, default gateway, and DNS settings.
- Command: `ipconfig /all`

### 2. Connectivity Testing
- Tested network connectivity using ICMP.
- Used ping and traceroute diagnostics to investigate connectivity.

### 3. DNS Troubleshooting
- Tested DNS name resolution using nslookup.
- Verified successful resolution of a public domain.

### 4. DHCP Troubleshooting
- Reviewed IP address assignment and DHCP-related network configuration.

### 5. Latency Analysis
- Examined ping response times and packet-loss results.

### 6. HTTPS Diagnostics
- Tested HTTPS connectivity using curl.
- Verified an HTTP 200 OK response.

## Key Skills Demonstrated
- Windows networking fundamentals
- TCP/IP configuration
- DNS and DHCP troubleshooting
- Connectivity and latency diagnostics
- HTTPS and HTTP response verification
- Technical documentation

## Results
Completed hands-on Windows network troubleshooting exercises and documented the diagnostic tools and methods used.
